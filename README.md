# 软件自动化测试 · 作品集

> 2027 届应届生求职作品集 —— 软件测试 / 测试开发方向

本人独立完成的两个自动化测试项目：一个**移动端 UI 自动化**、一个**接口自动化**，覆盖从测试框架搭建、用例设计、脚本编写到报告生成的完整流程。

---

## 项目一：拼多多 App 移动端自动化测试框架

**技术栈**：Python + pytest + Appium + UiAutomator2 + adb

- 覆盖商品搜索、收藏、浏览翻页、订单页面等 **5 个核心业务场景**
- 破解拼多多控件 ID 混淆、动态页面卡顿等真实难点，采用「多策略元素定位 + adb 直连」混合方案
- 实现用例隔离、会话复用、测试数据清理、闪退自动检测、多设备兼容回归等工程化能力

📄 [项目详情 & 简历模板](pdd_test/README.md)

## 项目二：ShopXO 商城接口自动化测试框架

**技术栈**：Python + requests + pytest + Allure

- 对商城登录接口做自动化测试，覆盖登录成功、密码错误、账号不存在、账号为空等场景
- 数据驱动（yaml）+ 分层断言 + 统一请求封装 + 日志轮转 + 中文 Allure 报告

📄 [项目详情 & 简历模板](shop_test/README.md)
